# We Connect — versiones

Cabina compartida para **Microsoft Flight Simulator 2020 y 2024**.

Este repositorio solo contiene las versiones publicadas de We Connect: el instalador, el zip y los archivos que la app usa para **actualizarse sola** (descarga únicamente lo que cambió).

## Descargar

Ve a [la última versión](../../releases/latest) y descarga **WeConnect-Setup.exe**.

- No necesita permisos de administrador.
- Windows puede avisar porque el instalador no está firmado: "Más información" → "Ejecutar de todas formas".
- Si ya tienes We Connect, actualiza desde la app: **Actualizar → Actualizar ahora**.
